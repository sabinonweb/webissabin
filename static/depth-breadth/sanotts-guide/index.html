sanoTTS सानो field guide

Tiny distilled neural TTS voices (294k to 2.3M parameters) that run in numpy, in the browser via WASM, and on a $3 ESP32-S3. This guide maps the two repositories, the training pipeline, every runtime, and exactly what to touch to add a language.

Ampixa/saanoTTS privateThe lab monorepo (470 MB): training tools, research, runtimes, evidence. The source of truth, and what gets published.
Ampixa/sanoTTS publicThe mirror, produced by tools/publish_public.py from docs/public/manifest.txt. It is currently ahead of private in places (see Known issues).

The voices

From the public README and web/voices/. An empty cell means unmeasured, not zero. SCOREQ is how it sounds, WER is whether words arrive; neither answers the other. No listening test has been run on any non-English voice.

LanguageVoiceweb/voices keyParamsSCOREQWERWhere

English WER is 24 held-out sentences; the ten 09-08 languages use 16 out-of-domain Tatoeba sentences (experiments/evidence/ood-tatoeba-20260908.json). Chinese WER is jieba-segmented; its comparable CER is 0.201 vs the teacher's 0.188.

Training a voice

Every multilingual voice came from one driver, tools/train_voice_from_piper.py. It runs the stages below, is resumable through per-stage done-files, and supports --dry-run. None of the older docs mention it; docs/roota-language-porting-recipe.md describes the same stages as manual commands with old paths.

Piper path (the one that ships languages)

Preflight

Refuses multi-speaker teachers, conv_pre not 256 wide (Piper "high" voices), and espeak voices piper can't speak. Rows 0-11 = smoke, 12-139 = eval, 140+ = train.

Build four probe packs

build_piper_vits_roota_probe_pack.py, deterministic (noise 0, length 1): smoke12, eval128, train-acoustic, train512-decoder.

Cut the teacher decoder

extract_piper_vits_decoder_cut.py → *-decoder-from-generator-input.onnx.

Duration student

train_roota_piper_duration_student.py

Acoustic (latent) student

train_roota_piper_latent_student.py --architecture token_context --latent-adv-weight 0.1

Decoder init + signature pack

verify_piper_decoder_torch_parity.py --export-checkpoint, then build_piper_vits_decoder_signature_pack.py.

Decoder student, then z-mix

train_roota_piper_decoder_student.py --variant piperlite --teacher-init-method importance, then again with --acoustic-latent-mix-prob 0.5.

Joint finetune

train_roota_joint_z_finetune.py --z-anchor-weight 0.5

Gate and package

run_roota_feedback_loop.py, then export_roota_self_contained_package.py → manifest.json (roota.raw-fp16.v1), weights.fp16.bin, piper-phoneme-config.json.

Shipped profile steps: duration 4000, acoustic 5000, decoder 2800, z-mix 2500, joint 4000. The script warns under 1900 text rows; the FLORES corpora gave ~1.9-2k rows per language, so ~1.75-1.84k training rows.

Pack schema

rows.json, summary.json, audio/, tensors/<row>_chunkNN.npz with phoneme_ids [N], w_ceil, generator_input [1,C,T]. C = 192 for Piper latents; 80 / 82 / 83 for Kokoro mel, +log-F0 +voiced, +N_pred. The joint trainer accepts only {80, 82, 83, 192}.

Kokoro path (nano lineage)

build_kokoro_corpus.py → kokoro_extract_front.py --with-prosody → build_kokoro_pack.py --f0-conditioning → same students. Shipped nano uses precompute_acoustic_mel100.py, train_tiny_vocos_student.py, train_e15_joint_nano_finetune.py, export_e12_nano_q8.py. The 83-channel chain script lives only on the k2 host.

The golden gate

Every port must reproduce the PyTorch reference. Fixtures are regenerated as whole versioned sets (each has SHA256SUMS), never edited in place.

TargetGate
make -C mcu testR7 vs test/fixtures/en_us_r7: corr > 0.98, 0.80 < rms ratio < 1.25
make -C mcu test-nanomin corr ≥ 0.98 over 8 rows; NaN is a hard fail

Adding a board

Implement mcu/include/snt_port.h in mcu/ports/<plat>/snt_port_<plat>.c: snt_dot_s8, snt_matvec_s8, snt_dot_s16s8, snt_matvec_s16s8, plus snt_weights_resident, snt_par_run, snt_now_us and snt_scratch_id (required, but missing from the header). Contract: len a multiple of 16, 16-byte aligned, exact int32 accumulation; snt_kernels_ref.c defines the semantics. Pass the 0.98 gate, then measure RTF with arduino/examples/BoardBenchmark and add it to BOARDS.md.

On ESP32-S3, the SIMD path is used only when weights are in RAM. Reading from flash-XIP silently returns garbage (corr 0.011).

From trained package to users

Package

export_roota_self_contained_package.py. The pip runtime reads this layout directly. For fr/ar, whose checkpoints are lost, repack_package_to_checkpoints.py rebuilds them from the package.

Browser bundle

export_voice_bundle.py --keys … → web/voices/<key>/{front,dec}_f32.bin + meta.json (with espeak_voice, g2p_voice_slot). New languages go in its NEW_LANGS table.

Shrink to fp16

shrink_voice_bundle_f16.py <key>, only when fp16 is the reference precision (the 09-08 voices). The browser widens to fp32 after download.

Register in the demo

web/index.html: the inline VOICES array, DEFAULT_TEXT, a langtable row, counts in the prose, mascot web/assets/mascots/<group>.png.

Host the weights

Upload web/voices/<key>/ to Hugging Face ampixa/sanoTTS (manual; no tool). For pip, add a pypkg/sanotts/tables/voices.json entry and a GitHub release asset (voices-v1 piperlite, voices-v2 nano).

Publish the mirror

Update docs/public/manifest.txt and README.public.md, run check_public_manifest_closure.py, dry-run publish_public.py, then --apply, commit and push the mirror by hand. pages.yml deploys web/ as-is.

Before the next publish: publish_public.py --apply deletes every mirror file that isn't in the mapping. The Chinese/pinyin work, pypkg v0.7.0, Hugging Face voice loading and the newer G2P tests exist only in the public mirror. Port them back to the private repo first.
