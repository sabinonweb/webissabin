Breadth first, then depth by problem

a reading map for sanoTTS, saanoTTS and nsl · 25 september 2026

These are the ideas the three repos actually lean on, in the order they build on each other. Each section covers one idea: where the repos use it, a question to answer before reading anything, and one or two things to read. It is not meant to be read in one sitting.

How to read this

Breadth passRead only the "Read:" link in each section, layer by layer. Mark it "skimmed".
Recall checkAnswer the "Before you read" question in your own words, without the tab open. Only then mark it "understood".
Depth passPick a problem below. Follow its path, reading the "Going deeper" links and the repo files.
Already in nslnsl/docs/CONCEPTS.html has one-line concept cards. This page is the reading layer behind them.

Go wide first. Take one section a day, starting at Layer 0 and moving up. For each one:

  1. Answer the question in the box before reading anything. Write your guess down, even if it's wrong.
  2. If there's an exercise, do it next.
  3. Open the file or number the section points at, so you know what the idea is for.
  4. Read the first link, and stop once you can answer the question.
  5. Close the tab and answer again in your own words. Mark it "skimmed" if you're still unsure, and "understood" only if you could explain it to someone else.

The next day, answer yesterday's question from memory before starting a new one.

When a real problem blocks you, stop going wide and go deep instead. Find the problem below and follow its path. It picks out the few sections, from any layer, that the problem needs.
