What the failures taught

Fine-tuning memorises the pile 28% · 29.7%

Both trainings drove pile loss near zero (4.9 → 0.2) and lost on new signers. ~590k weights vs ~180 paired pile clips: the shortcut (camera, rest pose, one signer's habit) always wins. memorised, not learned.

The ceiling is chances, not weights D · T3

Same frozen model: 28.0% with one pile answer vs 43.2% with two or more (clipped); 34.7% vs 52.2% under K=2. 778 of 1,056 tests get a single shot. No layer invents a missing second example — only filming (or mining) does.

Order beats blur T · T2

Mean-pooling erases speed: [up + roof]/2 looks the same for fast and slow. Keeping start/end halves (K=2) lets roof find roof: 32.0% → 39.3%, REAL. Finer slices (K=8) re-brittle on speed — coarser wins.

Sentences break the finder L · L2

Citation matching inside sentences: 27.3%, and trimming rest doesn't move it (identical 6 hits). Best windows land on hands-down; whole-clip averaging ties windows at 27.3% — the fixed rule family is exhausted. Neighbours blend in (coarticulation), rest matches rest (~0.9 > true 0.85), hubs (नागरिक wins 4 unrelated sentences) dominate.

What we're planning

  1. Resolve the H mismatch first. Same data scores 27.3% in spot_eval but 18.2% inside spot_head — check-everything before any head claim lives or dies.
  2. Spotter head on watched windows (Exp H). 5 learned weights, leave-one-word-out over 22 watched sentences; bar ≥40% + REAL to scale, tie ~27% parks sentences for good. Prediction: supervision, not cutoffs, is the missing ingredient.
  3. Ship the clipped finder. K=2 at 39.3% first guess / 56.2% top-5 (71.2% on 2+ pile words): dictionary lookup with 5 human-pickable candidates, no training, nothing blocked.
  4. Film the 388 seconds. Pilot the top 10 rows, re-run T3; mass-film only if thin words flip 1→2+ and move the score. Proven lift: +15 pts real vs +0.3 fake.
  5. Parliament tight-subset mining. Re-anchor gold/g2 rows with citation galleries, spot-check ~20, harvest sentence examples for the spotter — never train on raw weak labels (lag + gist + 40% unlabeled).
