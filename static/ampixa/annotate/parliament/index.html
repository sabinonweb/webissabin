How to annotate

  • Watch a short stretch first at 1×, then go back and mark at 0.5×.
  • Mark every sign you recognise: start when the hand begins the sign, end when it finishes. Don't include the movement to the next sign.
  • Write the Nepali word you'd use for the sign, not the caption text.
  • Not sure what it is? Still mark it and untick I'm sure. Unsure marks are useful.
  • Names and places spelled letter by letter: choose fingerspelled and type the word.
  • Work in 10–15 minute stretches. Your work saves automatically in this browser.
  • Parliament repeats formal phrases (माननीय सदस्य, सभामुख, प्रतिनिधि सभा). Mark a repeated phrase as one sign if the interpreter signs it as one unit, and say so in the note.
  • Start after the news annotation is done: news is shorter and easier to learn the tool on.
